# هدف این سند

این سند مرجع کامل طراحی رابط کاربری (UI) نرم‌افزار SMM360 VIP Care است.

تمام صفحات، فرم‌ها، پنل‌ها، دکمه‌ها، رنگ‌ها، فاصله‌ها، آیکون‌ها، داشبوردها و اجزای رابط کاربری باید مطابق این سند طراحی شوند.

هیچ صفحه‌ای خارج از این استاندارد ساخته نخواهد شد.
