# استانداردهای امنیتی SMM360

## امنیت کاربران

- ورود فقط با نام کاربری و رمز عبور
- امکان ورود دو مرحله‌ای (در نسخه‌های آینده)
- قفل شدن حساب پس از چند ورود ناموفق
- ثبت آخرین زمان ورود

---

## سطوح دسترسی

- مدیر سیستم
- پذیرش
- درمانگر
- پزشک
- اپراتور دستگاه
- مشاهده‌کننده

هر کاربر فقط به بخش‌های مجاز خود دسترسی دارد.

---

## امنیت اطلاعات

- اطلاعات سلامتجویان محرمانه است.
- حذف اطلاعات فقط توسط مدیر امکان‌پذیر است.
- تمام تغییرات ثبت می‌شوند.
- هیچ اطلاعاتی بدون مجوز قابل مشاهده نیست.

---

## ثبت رویدادها

ثبت موارد زیر الزامی است:

- ورود
- خروج
- ایجاد پرونده
- ویرایش
- حذف
- چاپ
- تهیه نسخه پشتیبان
- بازیابی اطلاعات

---

## امنیت پایگاه داده

- استفاده از SQLite
- جلوگیری از ثبت اطلاعات تکراری
- اعتبارسنجی اطلاعات قبل از ذخیره
- حفظ یکپارچگی داده‌ها

---

## نسخه پشتیبان

- تهیه نسخه پشتیبان دستی
- تهیه نسخه پشتیبان خودکار
- امکان بازیابی کامل اطلاعات

---

## امنیت فایل‌ها

- تصاویر
- گزارش‌ها
- فایل‌های ضمیمه

همگی باید با شناسه سلامتجو و شناسه ویزیت ذخیره شوند.

---

## استاندارد آینده

- رمزنگاری اطلاعات
- امضای دیجیتال
- Cloud Security
- API Security
- Audit کامل

# استاندارد امنیت ورود

## قوانین ورود

- فقط کاربران ثبت شده اجازه ورود دارند.
- هر کاربر فقط یک Role فعال دارد.
- ورود بدون نام کاربری یا رمز عبور مجاز نیست.
- رمز عبور به صورت رمزنگاری شده نگهداری می‌شود.
- Session بعد از ورود ایجاد می‌شود.

---

## ثبت رویدادها

در هر ورود موارد زیر ثبت شوند:

- UserID
- Username
- Date
- Time
- IP Address (نسخه آینده)
- Device Name
- Operating System
- Login Result

---

## ورود ناموفق

ثبت موارد زیر:

- تعداد دفعات
- زمان
- علت

بعد از پنج تلاش ناموفق:

- قفل موقت حساب

---

## خروج

در هنگام خروج:

- پایان Session
- ثبت زمان خروج
- ثبت مدت زمان استفاده

---

## قوانین آینده

- ورود دومرحله‌ای (2FA)
- ورود با اثر انگشت
- ورود با تشخیص چهره
- ورود با کارت هوشمند
- ورود با Microsoft Account
- ورود با Cloud Authentication
