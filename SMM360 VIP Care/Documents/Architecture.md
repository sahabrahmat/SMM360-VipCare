# هدف پروژه

هدف از توسعه SMM360 VIP Care ایجاد یک سامانه جامع، هوشمند، آفلاین و توسعه‌پذیر برای مدیریت کامل فرآیند سلامتجو از لحظه ورود تا پایان درمان و پیگیری‌های بعدی است.

این سامانه باید بتواند:

- اطلاعات سلامتجو را یک‌بار دریافت کند.
- اطلاعات را بین تمام بخش‌ها به اشتراک بگذارد.
- از ورود اطلاعات تکراری جلوگیری کند.
- پزشک را در تشخیص و درمان یاری کند.
- تمام تغییرات را ثبت نماید.
- گزارش‌های دقیق، مستند و قابل استناد تولید کند.
- برای سلامتجویان ایرانی و غیرایرانی قابل استفاده باشد.
- در صورت قطع اینترنت نیز بدون اختلال فعالیت کند.

# معماری کلان سامانه (Enterprise Architecture)

معماری SMM360 VIP Care به صورت ماژولار (Modular Architecture) طراحی شده است.

در این معماری، هر بخش مستقل توسعه پیدا می‌کند اما تمام بخش‌ها از قوانین یکسانی پیروی می‌کنند.

هدف این معماری عبارت است از:

- توسعه آسان
- نگهداری ساده
- جلوگیری از وابستگی زیاد فایل‌ها
- افزایش سرعت توسعه
- امکان افزودن ماژول‌های جدید بدون تغییر هسته سیستم
- قابلیت توسعه چندساله

---

# معماری لایه‌ای سیستم

سامانه از چند لایه اصلی تشکیل شده است.

```
Presentation Layer
        │
        ▼

        ▼

        │
        ▼

        ▼
```

تمام ارتباط‌ها باید از طریق Core انجام شوند.

# شناسه سلامتجو

برای هر سلامتجو دو شناسه تولید می‌شود.

---

## شناسه پرونده

ساختار:

```
SMM360-YY-MM-###
```

نمونه:

```
SMM360-05-04-001
```

قوانین:

- YY دو رقم آخر سال شمسی
- MM ماه شمسی
- ### از 001 شروع می‌شود.
- در ابتدای هر ماه مجدداً از 001 آغاز می‌شود.
- این شناسه هرگز تغییر نمی‌کند.

---

## شناسه ویزیت

```
V01

V03

...
```

# معماری اتاق درمان روشنک (Roshanak Therapy Room)

اتاق درمان روشنک یکی از اصلی‌ترین بخش‌های سامانه SMM360 VIP Care است.

این بخش محل اجرای درمان، دریافت اطلاعات تجهیزات، ثبت نتایج درمان و مقایسه وضعیت سلامتجو قبل و بعد از درمان می‌باشد.

تمام داده‌های تولید شده در این اتاق بخشی از پرونده دائمی سلامتجو محسوب می‌شوند.

---

<!-- ========================================================== -->

# اهداف اتاق روشنک

اهداف اصلی این بخش عبارت‌اند از:

- اندازه‌گیری وضعیت سلامتجو
- ثبت اطلاعات تجهیزات
- اجرای پروتکل درمان
- مقایسه قبل و بعد درمان
- تولید گزارش درمان
- ارسال اطلاعات به پزشک
- ثبت نتایج برای جلسات آینده

# معماری کاربران، نقش‌ها و مجوزها

سامانه SMM360 VIP Care بر اساس معماری

Role Based Access Control (RBAC)

طراحی شده است.

اما علاوه بر نقش (Role)، از سیستم مجوز (Permission) نیز استفاده می‌شود.

این ساختار باعث می‌شود پروژه بدون تغییر معماری بتواند سال‌ها توسعه پیدا کند.
